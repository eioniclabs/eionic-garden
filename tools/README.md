# Map Replay Tool

A lightweight, client-side HTML tool for visualizing agent movement and zone activity from Eionic simulation logs.

---

## How to Use

1. Open `replay.html` in any modern browser (Chrome, Firefox, Edge, etc.).
2. Click "Load Log" and select a `map_log.txt` file from any experiment folder.
3. Use the playback controls:
   - **Play / Pause** — run the simulation continuously
   - **Step Forward / Backward** — navigate tick by tick
   - **Speed Slider** — adjust playback speed
4. Agent positions and zone boundaries will be rendered on the map.

---

## Requirements

- No server needed — runs entirely in your browser.
- No internet connection required.
- Works with any `map_log.txt` generated by Eionic simulations.
