This project uses data from **Open English WordNet** (2025 Edition).

- **Title:** Open English WordNet (2025 Edition)
- **Author:** Open English WordNet contributors / Global WordNet Association

- **Web interface:** https://en-word.net/

  https://creativecommons.org/licenses/by/4.0/

Open English WordNet is a fork of Princeton WordNet, developed under an
open-source methodology by the Open English WordNet contributors. The 2025
Edition data was used in the construction of the lexicon in this repository
(v4 and later).

**Changes were made.** The original data was extracted, filtered, and
compiled into clause / frame / sense format for use by the local lexicon.
The transformation is described in the lexicon build scripts under
`devtools/` (not published).

## How to cite

If you use this work and need to cite the underlying wordnet data, cite
Open English WordNet directly:

> Open English WordNet contributors. (2025). *Open English WordNet* (2025
> Edition) [Data set]. Global WordNet Association.
> https://github.com/globalwordnet/english-wordnet

For the lexicon built on top of it, cite this repository.
